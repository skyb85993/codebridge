# 파일 출력 규약 (관대 모드 헤더)

브릿지 평탄화(flatten)가 모든 웹 전송 프롬프트의 첫 부분에 자동으로 붙인 지시문.
(Phase 1에서 flatten 구현 시 이 파일 내용이 그대로 사용된다.)

---

[파일 출력 규약 — 반드시 지켜 주세요]
1. 파일을 만들거나 수정할 때는 반드시 코드펜스( ``` )로 감싸 주세요.
2. 펜스의 첫 줄에 경로 주석을 적어 주세요. 예(Luau):
   -- path: ServerScriptService/GameManager.lua
3. 파일 수정 시에도 파일 전체를 다시 출력해 주세요.
   (부분 수정 지시는 별도 도구 형식으로 안내가 있을 때만 사용)
4. 파일 이름·폴더는 추측하지 말고 명확한 경로로 적어 주세요.
5. 코드 설명은 짧게, 파일 블록은 빠짐없이. 화면에는 파일 블록 외에 진행 요약만 적어 주세요.
